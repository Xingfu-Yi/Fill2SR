Fill2SR

Repurposing Inpainting Diffusion Transformers
for Real-World Super-Resolution

Xingfu Yi·Xiaoxue Yu

Paper ↗ Code ↗ Model weights ↗

Fill2SR adapts an inpainting diffusion transformer for real-world super-resolution. It brings low-quality image evidence into the model’s native inpainting interface and refines the model with real-degradation training pairs.

THE IDEA

From filling regions
to restoring images.

Fill2SR repurposes the generative prior of an inpainting diffusion transformer for real-world super-resolution.

01

Repurpose an inpainting model

Built on FLUX.1-Fill-dev with FLUX.1-Redux-dev, Fill2SR adapts a pretrained foundation model to restore low-quality images.

02

Bring in image evidence

The Inpainting-Interface Evidence Adapter (IIEA) places the low-quality observation in the native masked-image slot under a full-image mask.

03

Explore Ours-Full

RCDT transfers degradation patterns from real images onto clean targets to construct training data. The released Ours-Full LoRA includes this refinement.

Reproduction details & data source

The 2K preset follows the model’s pixel budget and aspect-ratio handling. For these 256 × 256 inputs, it produces 1,536 × 1,536 outputs; it does not fix the longest edge at 2,048 pixels. Every downloaded PNG is the unmodified source or model output.

RealLQ250 was released with DreamClear. Image rights remain with their respective owners. Our selection is a qualitative showcase, not an aggregate benchmark evaluation.

Download the image manifest for image IDs, hashes, dimensions, model version and sampling parameters. Ours-Base weights, training code and RCDT data generation code are not included in this release.

The Ours-Full weights are subject to the upstream FLUX.1 [dev] Non-Commercial License. See the repository’s license and attribution.
